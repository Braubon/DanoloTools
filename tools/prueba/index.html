Abre Wildcarder con el lanzador

Para que la web lea sola la carpeta wildcards del proyecto, ábrela con el lanzador que hay junto a este archivo. Se abre el navegador con todo cargado y, cada vez que guardes un .txt, la web se actualiza.

wildcarder/ ├─ Wildcarder (Windows).bat ← doble clic en Windows ├─ Wildcarder (Mac).command ← doble clic en Mac ├─ wildcarder-linux.sh ├─ index.html └─ wildcards/ ← tus .txt

El lanzador abre una ventana negra: déjala abierta mientras uses la web y ciérrala para terminar.

Sin lanzador también funciona, pero tendrás que elegir la carpeta cada vez que abras la web.

Sintaxis

      
La misma que Dynamic Prompts e Impact Pack en ComfyUI.

      

        
__color__
Una línea al azar de wildcards/color.txt.

        
__color/warm__
Subcarpetas: wildcards/color/warm.txt.

        
__color/*__
Junta todas las líneas de todos los .txt dentro de color/ (subcarpetas incluidas) y elige una.

        
__*/fantasy__
El asterisco vale en cualquier parte del nombre.

        
{red|blue|green}
Elige una de las opciones.

        
{2$$a|b|c}
Elige 2 distintas, separadas por coma.

        
{1-3$$a|b|c}
Entre 1 y 3 opciones distintas.

        
{2$$ and $$a|b|c}
Separador propio: «a and c».

        
{3::a|b}
Peso: «a» sale 3 veces más que «b».

        
{__color/warm__|__color/cool__}
Las opciones pueden contener wildcards, y al revés.

      

      
Dentro de los .txt

      
Una opción por línea. Las líneas vacías y las que empiezan por # se ignoran. Repetir una línea hace que salga más a menudo. Una línea puede llevar otros wildcards y variantes: así se anidan las listas.

      
El nombre del wildcard es la ruta del archivo dentro de wildcards/, sin .txt. Un archivo y una carpeta pueden llamarse igual: color.txt mezcla lo que hay en color/.

      
Atajos

      
Ctrl + Enter genera. Mientras escribes __, las flechas y Tab o Enter eligen un wildcard. Doble clic en un archivo de la lista lo inserta en el prompt. Clic en una parte de un resultado abre el archivo del que sale.
