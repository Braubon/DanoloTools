# Base de datos

Un directorio por libro, registrado en `manifest.json`. Cada `atlas.json` declara sus archivos (uno por colección) y sus reglas opcionales.

- Esquema completo: `../docs/esquema-datos.md`
- Cómo añadir un libro: `../.agents/skills/incorporar-atlas/SKILL.md`
- Validar: `node tools/validar.mjs` desde la raíz del proyecto.
